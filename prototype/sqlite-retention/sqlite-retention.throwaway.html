持久 SQLite 该留多少 Usage Facts？

20k 是热查询工作集，不是数据库保留策略。源日志消失不等于库应删除。容量硬顶按 bytes 或 rows 先到者触发：superseded → >90d 原子 compact → 最旧 rollup（Coverage=partial）→ 7–90d raw。7 天保护窗超限则暂停 ingest，不静默删。Reset Data 清全部 App 遥测，不改源日志，也不保证删掉用户另存的导出。

本页只推动保留策略状态机。字节与查询区间来自本地 Node/SQLite harness，不是 AppKit 数字，也不是 fleet SLO。
