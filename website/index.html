Frequently asked questions.

What data does Agent Metrics collect?

It derives normalized token and performance facts from supported local coding-agent files. The app surfaces quality and coverage when a source is incomplete or unavailable.

Why are Output Throughput and Decode TPS separate?

Output Throughput describes aggregate agent output over a shared time window. Decode TPS describes one model call's generation phase. Keeping them separate makes comparisons honest.

Which coding agents are supported?

Version 0.2.0 supports local Codex and Claude Code activity on Apple silicon Macs running macOS 14 or later.

How do updates work?

Agent Metrics checks the stable Sparkle feed automatically and always asks before installing. You can also follow releases on GitHub.
