Defined before displayed

Each metric answers one question.

Output Throughput

Selected output tokens divided by the shared duration of a 3, 5, or 10 minute sliding window. It is not per-call TPS.

Token Burn

Normalized, mutually exclusive token parts over a fixed 600-second window. It is not TPM and never adds overlapping counters.

Calls

Distinct stable Model Call IDs per minute. If a source cannot supply a stable ID, calls are unavailable rather than guessed.

Decode TPS

A per-model-call decode rate excluding time to first token. It requires Enhanced Telemetry and stays unavailable when its required fields cannot be joined.

Trend details pair values with measurement quality, data state, coverage, freshness, source authority, and definition version.

Enhanced Telemetry is off by default. Its loopback receiver is unauthenticated, so enable it only when you trust local processes on your Mac. The app does not change shells, environment variables, or coding-agent configuration.

Local storage and controls

Your data stays under your control.

Agent Metrics reads supported local files and stores normalized usage facts in a local SQLite store. It does not require an account or hosted analytics service. Its expected external network activity is automatic and user-initiated update checks against the configured feed.

  • The most recent 7-day window is protected during retention cleanup.
  • At capacity thresholds, older data may be pruned and coverage shown as partial; ingestion can pause at the hard limit.
  • Privacy-safe diagnostics use an allowlist. Reset Data clears telemetry data, but cleanup and space reclamation can complete later.

FAQ

Practical details.

Does it upload my agent activity?

No hosted analytics service is required. Automatic and user-initiated update checks are the expected external network activity; enabling Enhanced Telemetry creates an unauthenticated local loopback receiver.

Why can a value be partial or unavailable?

Sources differ in their durable fields and boundaries. Agent Metrics surfaces missing coverage and does not substitute a different measurement.

How do I troubleshoot or clear data?

Use Data & Diagnostics for an allowlisted diagnostic preview, copy, save, or public-issue preparation; use Reset Data after reviewing its scope.

How are updates delivered?

Public Beta is a product-maturity label, not an update channel. The production update feed contains only published, non-prerelease GitHub Releases.
